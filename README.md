# Sales Analytics Dashboard Using Python and Power BI

## Project Overview

This project focuses on analyzing sales data using Python and Power BI. The project provides useful insights into sales, profit, quantity, products, categories and regional performance through data analysis and interactive dashboards.

## Problem Statement

Businesses generate large amounts of sales data, but it can be difficult to identify important trends and performance patterns from raw data. This project aims to analyze sales data and present meaningful insights using Python and Power BI.

## Dataset Description

The dataset contains sales transaction information such as Order ID, Order Date, Customer ID, Product, Category, Region, State, Quantity, Sales, Profit, Payment Mode and Customer Type.

## Tools Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Power BI
* Excel/CSV
* Git and GitHub

## Data Cleaning Process

* Inspected the dataset.
* Checked column names and data types.
* Identified missing values.
* Handled missing values.
* Removed duplicate records.
* Checked incorrect or inconsistent records.
* Prepared the cleaned dataset for analysis.

## Exploratory Data Analysis

EDA was performed to understand sales, profit, quantity, regional performance, product demand and monthly sales trends. Descriptive statistics and correlation analysis were also performed.

## Visualizations

The project includes the following visualizations:

1. Sales by Region
2. Monthly Sales Trend
3. Profit by Category
4. Sales by Category
5. Quantity Sold by Product

The visualization files are available in the `Visualizations` folder.

## Power BI Dashboard

The Power BI dashboard contains:

* Total Sales KPI
* Total Profit KPI
* Total Orders KPI
* Total Quantity KPI
* Sales by Region
* Monthly Sales Trend
* Profit by Category
* Sales by Category
* Quantity Sold by Product

The dashboard also includes slicers for Year, Region, Category, Payment Mode and Customer Type.

## Key Insights

* Sales performance varies across different regions.
* Monthly sales show changes over time.
* Product categories have different sales and profit performance.
* Some products have higher demand based on quantity sold.
* Sales and profit analysis helps identify profitable business areas.

## Business Recommendations

* Focus on high-performing regions and product categories.
* Improve low-performing products through promotions and targeted marketing.
* Monitor monthly sales trends for better business planning.
* Maintain availability of high-demand products.
